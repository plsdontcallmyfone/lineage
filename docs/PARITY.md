# Parity with Veemo / Cellumo, done for real

Owner direction (2026-10-07): match every surface Veemo and Cellumo present, with a working system behind each one. Their code is at github.com/nuttumrunit/veemo and github.com/nuttumrunit/Cellumo (same developer, same treasury address). We copy capabilities, never their branding, copy text, logo or addresses.

Status key: DONE (built and tested here), BUILDING (a lane is on it), PLANNED (scheduled, with the milestone), OWNER (needs an owner decision or input).

## Where they cut corners and we must not

- No number on screen that is not produced by Core from real runs or read from chain.
- No animation pretending to be agent activity. Idle is shown as idle.
- No published split, burn or treasury that the chain does not implement.
- Contract addresses come from one config source and are shown exactly as configured, never edited by hand into the page.
