Their code is at github.com/nuttumrunit/veemo and github.com/nuttumrunit/Cellumo (same developer, same treasury address). We copy capabilities, never their branding, copy text, logo or addresses.

## Where they cut corners and we must not

- No number on screen that is not produced by Core from real runs or read from chain.
- No animation pretending to be agent activity. Idle is shown as idle.
- No published split, burn or treasury that the chain does not implement.
- Contract addresses come from one config source and are shown exactly as configured, never edited by hand into the page.
